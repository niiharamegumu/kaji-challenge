# Task

## Goal

- 月次締めを自動 Job からユーザー主導へ変更する。
- 全ページで最古の未締め月を案内し、サマリーで確認して締められるようにする。
- 全過去期間の日次・週次完了状態を補正し、締め済み月は警告後に再確定する。
- 不要になる API、月次 Job、重複防止データを整理する。

## Current facts

- 日次・週次 Job が `monthly_penalty_summaries` に減点を累積している。
- 月次 Job は毎月 7 日 01:30 JST に実行され、発動ルールと `is_closed` を確定する。
- 過去補正は当月かつ未締めに限定され、削除済みタスクは更新できない。
- タスク設定とルール閾値には履歴がない。

## Success criteria

- 翌月 1 日以降、最古の対象月を全ページで案内できる。
- 月またぎ週を週末月へ帰属させ、対象月を原子的に締められる。
- 締め済みを含む全過去期間の有効なタスクを補正し、月全体を現在設定で再計算できる。
- 月次 Job と旧 API を撤去し、日次・週次 Job の再実行安全性を確保する。
